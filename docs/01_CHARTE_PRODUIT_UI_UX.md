# CHARTE PRODUIT & UI/UX — CAR ONE PLUS

## 1. ADN
CAR ONE PLUS doit donner une sensation de produit automobile premium, rapide, fiable et futuriste.
Mots-clés : mobilité, confiance, contrôle, simplicité, technologie, revenu.

## 2. Direction artistique
Palette :
- Noir profond : #0B0B0D
- Blanc : #FFFFFF
- Gris interface : #F3F4F6 / #D9DDE3
- Rouge accent : #E53935
- Vert statut : #16A34A
- Jaune alerte : #F59E0B

Le rouge sert aux actions critiques, états d'alerte et éléments de marque.
Le vert sert aux disponibilités, validations, paiements réussis et statuts OK.
Le noir/blanc structure l'interface.

## 3. Style
- Cartes très arrondies, mais pas excessivement décoratives.
- Grande photographie du véhicule.
- Typographie sans-serif moderne, forte hiérarchie.
- Icônes simples et cohérentes.
- Cartographie plein écran lorsque la recherche géolocalisée est centrale.
- Bottom sheet pour les détails rapides.
- Animations courtes : 150–250 ms.
- États de chargement avec skeletons.
- Accessibilité : contrastes élevés, tailles tactiles >= 44 px.

## 7. Écran de recherche
En haut :
- destination ou position actuelle ;
- date/heure de début ;
- date/heure de fin ;
- bouton carte/liste.

Filtres :
- catégorie ;
- prix ;
- distance ;
- transmission ;
- carburant/électrique ;
- nombre de places ;
- volume utile pour utilitaires ;
- kilométrage inclus ;
- livraison ;
- clé digitale ;
- réservation instantanée ;
- note ;
- professionnel/particulier ;
- équipements.

## 8. Fiche véhicule
- galerie photos/vidéo ;
- marque/modèle/version ;
- localisation approximative avant réservation ;
- note et nombre d'avis ;
- prix ;
- calendrier ;
- kilométrage inclus ;
- dépôt de garantie ;
- protection/assurance applicable ;
- conditions conducteur ;
- équipements ;
- mode de remise : clé digitale / rendez-vous / agence ;
- politique carburant/recharge ;
- bouton Réserver.

## 9. État des lieux
Parcours guidé :
- 4 côtés du véhicule ;
- avant/arrière ;
- roues/pneus ;
- intérieur ;
- compteur ;
- carburant/batterie ;
- photos horodatées ;
- détection assistée des dommages ;
- validation par les deux parties lorsque nécessaire.

## 10. Identité de marque
Nom : CAR ONE PLUS
Promesse : « Votre mobilité. Votre voiture. Votre revenu. »
Ton : direct, rassurant, premium, sans jargon.

## 11. Règle importante
Ne pas reproduire pixel par pixel les interfaces des concurrents. On reprend les fonctionnalités utiles et les bonnes pratiques, puis on crée une identité CAR ONE PLUS propre et reconnaissable.
