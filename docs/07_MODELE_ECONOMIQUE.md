# MODÈLE ÉCONOMIQUE — CAR ONE PLUS

## Commission
Commission plateforme cible : 5 % par location.

## Revenus complémentaires possibles
- frais de service ;
- livraison ;
- protection/assurance via partenaire ;
- options ;
- abonnement propriétaire professionnel ;
- abonnement locataire ;
- frais de gestion de flotte ;
- télématique ;
- partenariats constructeurs ;
- financement/maintenance via partenaires ;
- marketplace B2B.

## Exemple
Location : 800 €
Commission 5 % : 80 €
Versement propriétaire : 720 € avant autres frais applicables.

Le calcul exact doit être configurable et présenté avant paiement.

## Stratégie propriétaire
Promesse :
« Votre véhicule travaille pendant que vous ne l'utilisez pas. CAR ONE PLUS gère la location, les réservations, les paiements et le suivi. »

## Stratégie professionnel
Promesse :
« Transformez votre flotte en canal de revenus supplémentaire sans multiplier les outils. »

## Stratégie locataire
Promesse :
« Une voiture, un utilitaire ou un deux-roues près de vous, réservé depuis votre téléphone. »
